
# PhishGuard - Graduation Project Web App

## Run locally
1) Create venv:
   python -m venv .venv
2) Activate:
   - Windows: .venv\Scripts\activate
   - Mac/Linux: source .venv/bin/activate
3) Install:
   pip install -r requirements.txt
4) Start:
   uvicorn app.main:app --reload
5) Open:
   http://127.0.0.1:8000
